# Тесты

Тесты запускаются обычным PHP CLI, без PHPUnit и Composer.

```bash
php tests/run.php imagick
php tests/run.php gd
```

В режиме `imagick` требуется настоящее расширение `ext-imagick`, в режиме `gd` — настоящее `ext-gd`. При отсутствии расширения тест завершается **ошибкой**, а не `SKIP`. Оба режима запускают отдельные проверки без расширений (`php -n`) на имитациях обработчиков и ошибок.

GitHub Actions: `.github/workflows/tests.yml`. Сначала отрабатывает Imagick, затем GD; оба задания проверяются на PHP **7.2, 8.2 и 8.4**. Для PHP 7.2 используется `ubuntu-22.04`, для остальных версий — `ubuntu-latest`.

| Файл | Проверки |
|---|---|
| `smoke.php` | Базовое API, коды ошибок, отсутствие расширений |
| `bc_review.php` | Все 17 исходных публичных методов, 4 `protected`, сигнатура `load()` |
| `icc_profile.php` | ICC v2/v4, сигнатура и извлечение имени |
| `source_contract.php` | Сообщения и строковые значения в PHP-исходниках без русского текста |
| `exif_orientation.php` | EXIF 1–8, TIFF little/big endian, повреждённые данные, нормализация |
| `imagick_stub.php` | Выбор, ICC, конверсия, очистка, ошибки Imagick (имитация) |
| `imagick_orientation_legacy_stub.php` | Все 8 ориентаций, отражения, сохранение EXIF, ошибки поворота без `autoOrientImage()` |
| `gd_stub.php` | Выбор GD, трансформации, наследование, ошибки GD (имитация) |
| `fallback_stub.php` | Автоматическое переключение при ошибке декодирования Imagick |
| `real_backend.php` | Реальные PNG/JPEG, цвета, ориентация 1–8, прозрачность, размеры, ресайз, кадрирование, сохранение, output, ошибки, EXIF/GPS/XMP и ICC |

В ходе теста создаются временные изображения; внешний `convert`, `exiftool` или сетевое соединение не нужны. Необрабатываемые форматы и ограничения кодеков PHP/ImageMagick зависят от установленной версии расширений; PDF/SVG/TIFF специально не ограничиваются библиотекой.
